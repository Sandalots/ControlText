# ControlText

A text-based adventure game inspired by **Control** (2019), the action adventure game by Remedy Entertainment.

## About

You play as Jesse, exploring the mysterious Oldest House—a sprawling paranormal facility. Uncover secrets, find your brother Dylan, and confront the mysterious Hiss entity threatening the building.

## How to Play

Type commands to explore rooms, fight enemies, collect items, and solve puzzles. The game guides you with text descriptions and hints as you progress.

## Running the Game

- **Standalone**: Load in SWI-Prolog with `?- [control].`
- **Web version**: Start the server with `?- [server].`

Enjoy your descent into the Oldest House.
